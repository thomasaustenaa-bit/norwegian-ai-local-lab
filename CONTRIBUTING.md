# Contributing

Thanks for helping make local AI easier to understand and reproduce.

## Useful contributions

- reproducible PC and runtime setup guides;
- benchmark records with full hardware, model, and setting details;
- Somali/English evaluation material with clear authorship and license;
- bug reports with versions and steps to reproduce;
- accessibility, documentation, and privacy improvements.

## Before submitting

- Keep prompt text and model output out of committed run records unless the content is explicitly licensed and safe to share.
- Never commit credentials, private documents, or personal data.
- Label estimates and unmeasured claims clearly.
- Include the command, versions, hardware, model quantization, and settings needed to reproduce a measurement.
- For language evaluations, explain how fluent review was done and its limitations.

Small, focused pull requests are easiest to review. Please open an issue first for substantial changes to the architecture or data handling.
