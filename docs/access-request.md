# Provider access request — factual template

Use this as a starting point only when a provider has a relevant application or contact route. Replace the bracketed fields with verified details. Do not say the project has customers, a registered company, benchmark results, or institutional backing unless that is true and documented.

## Draft

**Subject:** Request for time-limited evaluation access for an open local-AI assistant evaluation project

It does not yet implement persistent project memory or publish benchmark results.

## Before sending

- Confirm the current offer exists and is open to applicants in Norway.
- Confirm who will own and administer any workspace or account.
- State the exact use case, duration, and requested seat count; do not request unrelated subscriptions.
- Do not claim that this repository qualifies for a free plan or trial.
- If a payment method or automatic renewal is required, review the terms and cancellation date before accepting.
